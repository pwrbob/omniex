# OmniEx logo

The selected mark: a fingerprint with the digest at its core.

| File | Use |
| --- | --- |
| [`omniex-logo.svg`](omniex-logo.svg) | Full logo (mark + wordmark) on light backgrounds |
| [`omniex-logo-dark.svg`](omniex-logo-dark.svg) | Full logo on dark backgrounds |
| [`omniex-mark.svg`](omniex-mark.svg) | Mark only, for icons and favicons on light backgrounds |
| [`omniex-mark-dark.svg`](omniex-mark-dark.svg) | Mark only on dark backgrounds |

All files are self-contained SVG with a `viewBox`, so they scale without loss.
The dark variants are drawn for dark surfaces; their negative space is the
background, not white.
