`preview-marks.png` / `preview-logos.png` and their `-dark` counterparts are contact sheets
for all 26 at once.

Nothing here is wired into the brand assets; copy a folder out if one is worth developing.

If I had to pick, these four have the most life in them:

- `01-negative-hex` — survives at 16px, one shape, no gimmick.
- `09-ex-ligature` — a real monogram rather than an illustration.
- `17-glitch-hash` — the only one that says "broken apart" instead of "moved".
- `20-bar-arrow` — hash bars doing the work of an arrow, so "extract" costs no extra element.
