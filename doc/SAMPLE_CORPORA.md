# External sample corpora

Corpora used to validate extraction without checking artifacts into this
repository.

## Paired artifact and hash corpora

- **hashcat `tools/2hashcat_tests`** - <https://github.com/hashcat/hashcat/tree/master/tools/2hashcat_tests>.
  KeePass KDBX v4 files are paired with hashcat (`*.hash`) and John
  (`*.keepass2john`) serializations, and GPG OCB-AES private keys are paired
  with hashcat serializations. `scripts/check-paired-samples.py` clones this
  directory at run time and compares every paired artifact against the
  extracted hash.

## Artifact-only corpora

- **openwall/john-samples** - <https://github.com/openwall/john-samples>.
  Artifacts for most John `*2john` scripts. Passwords are in filenames or
  adjacent `password.txt` files; extracted hashes are generated by the
  `*2john` tools rather than stored in the repository.
- **openwall/john-tests** - <https://github.com/openwall/john-tests>.
  Hash vectors (`*_tst.in`) with known passwords, without the original
  artifacts.

The paired corpus is checked in CI. Artifact-only corpora can be used locally
with the pinned John scripts and `tests/extract_conformance.rs`.
