omniex — hash parser, renderer, and extractor

The extractor for everything.

Parse, render, and extract hashes for hashcat and John the Ripper — one binary instead of a pile of *2john scripts.

extraction

One artifact, every matching record

omniex extract reads an artifact and emits one rendered hash per line. Without --type, every extractor probes the input; auto-detection succeeds only when exactly one extractor reports confident structural recognition.

OptionBehavior
--type <slug> Name the extractor when a format has no reliable signature.
--all Run every confident extractor. Conflicts with --type and fails without partial output.
--tool john Render for John instead of hashcat.
--format human shows a field table per value, json emits machine-parseable output, and the default hash prints one hash per line.
--full Print complete field values instead of truncating long parameters.
--companion NAME=PATH Attach a sidecar input, such as a KeePass keyfile or an ENCDataVault enckey.
--opt NAME[=VALUE] Pass an extractor-specific option; --opt deep permits slower scans that inspect more than headers and partition tables.

What is checked in CI

  • 617 pinned files from 23 upstream projects, fetched at a locked commit and compared field by field with the reference *2john and *2hashcat output.
  • Conformance suites ask the real hashcat 8.0.0 and John jumbo builds to load what omniex emits. Neither path runs an attack.
  • Fixtures cover 163 artifact formats, including malformed and truncated inputs.
  • Cold-cache CI runs the same scripts in the same container image the local suite uses.

install

Install

Each release ships a static x86_64 Linux binary built with musl, so it runs without matching the build host's glibc. Building from a checkout needs Rust 1.90 or newer.

$ cargo install --path . 
$ omniex --help
The extractor for everything.

Usage: omniex <COMMAND>

Commands:
  parse     Parse hash strings and render them again
  identify  List the hash types that parse an input
  extract   Extract hashes from an artifact
  types     List the hash types available in this build
  show      Show the descriptor for one hash type

Prebuilt archives are on the releases page. Source builds use cargo install --path . from a checkout.
